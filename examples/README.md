# 抖音纯净模式（Safari · Userscripts）

在 Safari 上看抖音时：**首页零推荐、只留搜索框**；**搜索页点博主就地展开 TA 的前 4 条视频**，4 条看完明确提示「没有更多」；**博主主页显示全部视频**；**不限每日浏览数量**。全程不进入抖音的推荐流。

当前版本 **1.2.0**。左下角有个小徽章（`纯净模式 v1.2 · 搜索页 · 已看3条 · 搜索上限4（不限量）`），点它可以直接开关纯净模式——**这是判断脚本有没有生效最直观的方式**。

---

## 一、脚本做了什么

| 场景 | 处理方式 |
| --- | --- |
| 抖音首页（推荐流） | 推荐视频容器整块隐藏，视频元素禁止自动播放，页面只剩顶部搜索框 |
| 左下角徽章 | 显示当前模式、页面类型、已浏览计数、上限；**点击可一键开关** |
| 搜索页 | 抖音自己的瀑布流在你展开博主后隐藏；右侧出现一块干净面板，列出搜到的博主 |
| 点开某个博主 | 面板里**只渲染 TA 的前 4 条视频**，封面 + 标题 + 点赞/评论数 |
| 点播某条视频 | 在页面内浮层播放，**不跳转、不产生下一条推荐**；播完可关掉看下一条 |
| 4 条全部看完 | 面板底部出现「已看完全部 4 条 · 这个博主这里没有更多视频了」 |
| 博主主页（`/user/...`） | **显示并播放全部视频**，不隐藏、不限制、不插提示条 |
| 视频详情页 | 当前这条可正常播放（不自动播，页中会提示「点一下开始」）；**后续推荐被摁停并隐藏**，滚动/方向键「滑下一个」被拦截 |
| 每日浏览数量 | **不限量**（`AUTO_CLOSE_AFTER = 0`），不再弹告别页、不再自动关标签页 |

「浏览」的计数口径：**去重统计**——同一个视频看 10 遍仍只算 1 次。

## 二、安装（约 5 分钟，不需要 Xcode）

### 1. 装 Userscripts 扩展

App Store 搜索 **Userscripts**（作者 quoid，免费开源），安装后打开它一次，选择一个本地文件夹用来放脚本，例如：

```
~/Documents/userscripts
```

### 2. 开启 Safari 扩展权限

- Safari → 设置 → 扩展 → 勾选 **Userscripts**
- 点击 Userscripts 图标 → 选择该文件夹作为脚本目录
- 首次访问 `douyin.com` 时，点扩展图标把本站设为 **Always Allow on This Website**（必须，否则脚本不注入）

### 3. 放入脚本

把本目录的 `douyin-pure.user.js` 拷贝到上面那个脚本文件夹：

```bash
cp douyin-pure.user.js ~/Documents/userscripts/
```

然后在 Safari 里打开 `https://www.douyin.com/`。扩展会自动识别（必要时点扩展图标 → **Update Scripts**）。

### 4. 验证是否生效

- 首页应该只剩搜索框，一个推荐视频都没有
- 按 `⌥⌘I` 打开网页检查器 → 控制台，应看到 `[抖音纯净] 已启动`
- 控制台执行 `__dypm()` 可查看当前状态

## 三、调试与调整

脚本内置了几个控制台命令（Safari → 开发 → 显示网页检查器）：

| 命令 | 作用 |
| --- | --- |
| `__dypm()` | 打印当前模式、页面类型、已浏览计数、抓到的博主及视频数 |
| `__dypmReset()` | 把浏览计数清零、清空抓到的博主 |
| `__dypmRefresh()` | 立刻重绘右侧面板 |
| `__dypmState` | 直接查看状态对象 |

想改参数，编辑脚本开头这一段：

```js
var VIDEOS_PER_AUTHOR = 4;   // 搜索页每个博主显示的视频上限
var AUTO_CLOSE_AFTER  = 0;   // 0 = 不限量；填正数则看够 N 个后自动关标签页
```

## 四、三条规则速查

| 页面 | 规则 |
| --- | --- |
| 抖音首页 | 只留搜索框，零推荐 |
| 搜索页（`/search/...`） | 点博主就地展开**前 4 条**，看完提示没有更多 |
| 博主主页（`/user/...`） | **全部视频照常显示和播放**，不拦截 |
| 视频详情页 | 当前视频可播，后续推荐被切断 |
| 每日数量 | **不限** |

改规则只需要动脚本开头两个常量：`VIDEOS_PER_AUTHOR`（搜索页上限）、`AUTO_CLOSE_AFTER`（0 = 不限量）。

## 五、它是怎么绕过抖音改版的

抖音网页版的 DOM 类名几乎每周都在变，硬编码 `class` 名两周就会失效。所以这个脚本用了**双层策略**：

1. **主策略：接口拦截。** 在 `document-start` 阶段挂钩 `fetch` 和 `XMLHttpRequest`，读抖音自己的搜索接口（`/aweme/v1/web/general/search/single/`）和博主作品接口（`/aweme/v1/web/aweme/post/`）返回的 JSON，从中提取 `aweme_id / desc / cover / play_addr / author.sec_uid`，再用我们自己的界面渲染。JSON 字段名比 DOM 类名稳定得多。
2. **兜底策略：多重选择器 + 启发式。** 净化用的 CSS 同时写了 `[data-e2e="..."]`、`[class*="recommendList"]` 等多种形态；即使抖音改名，只要还能识别出视频容器就能兜住。

解析器还会主动排除非视频内容：`aweme_type === 68`（图文）、`aweme_type === 101`、带 `is_live/room_id` 的直播卡。

## 六、已知限制

- **推荐流的接口结构如果大改**，右侧面板可能抓不到博主。此时执行 `__dypm()` 看「抓到的博主」是否为空，把控制台输出发我即可修。
- **Safari 通常不允许脚本关闭标签页**（只有脚本自己开的窗口才允许）。所以「自动关闭」的实际行为是：先弹告别页，然后尝试 `window.close()`；若被拦截，0.9 秒后自动把这一页变成空白页 `about:blank`（脚本会改标题为 `✅ 已到量`，便于在标签栏辨认）。如果你有其他抖音标签页，只有当前这一个会被关。
- **计数存在浏览器本地**（Userscripts 的 GM 存储，退化时用 `localStorage`），换设备不共享，清除网站数据会重置。
- 只在 `www.douyin.com` / `douyin.com` / `www.iesdouyin.com` 生效，iframe 内不运行（`@noframes`）。

## 七、文件说明

| 文件 | 说明 |
| --- | --- |
| `douyin-pure.user.js` | **主交付物**，导入 Userscripts 即可用 |
| `testenv.js` | 测试用的最小 DOM 仿真环境（可变 fixture） |
| `selftest-parser.js` | 解析器自检：验证图文（aweme_type 68）与直播卡被排除、图片协议补全 |
| `selftest-cap.js` | 上限自检：接口给 10 条，面板只渲染 4 条；看完后出现「没有更多」 |
| `selftest-unlimited.js` | 不限量自检：看 30 个视频也不触发告别页 |
| `selftest-home.js` | 主页自检：博主主页不隐藏任何视频；上限与不限量配置正确 |

自检命令：

```bash
node --check douyin-pure.user.js
node selftest-parser.js && node selftest-cap.js && node selftest-unlimited.js && node selftest-home.js
```
